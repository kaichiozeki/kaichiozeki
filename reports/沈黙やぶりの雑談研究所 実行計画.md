# 沈黙やぶりの雑談研究所 実行計画

市場調査レポート（`reports/コミュニティ収益化 市場調査 日本.md`）と、質問への回答で決めた内容をもとにした実行計画です。
最初に使う原稿（プロフィール文、ショート動画の台本、note の記事）は `reports/沈黙やぶりの雑談研究所 最初の原稿.md` にあります。

## 2. コンセプト

**一文で：** 元ホストのしじま所長が、雑談が苦手な社会人に「沈黙を破る会話の型」を教える研究所。

### 他との違い
- 話し方の本や講座はたくさんあるが、「ホスト時代の接客で身につけた実戦の型」という切り口は少ない
- 練習会がないぶん、**すぐ使える具体的な一言**と、**会員の悩みへの個別の回答**で価値を出す

### ターゲットが広いことへの対策
「社会人全般」は人数が多いぶん、テーマがぼやけやすくなります。そこで、話題は**場面ごと**に分けて具体的にします。

| 場面 | 例 |
|---|---|
| 職場 | エレベーター、昼休み、移動中、給湯室 |
| 初対面 | 取引先、交流会、新しい部署 |
| 目上の人 | 上司、年上の取引先、義理の家族 |
| 飲み会 | 隣の人と話が続かない、輪に入れない |
| 日常 | 美容室、タクシー、近所の人 |
| 困ったとき | 沈黙、話が噛み合わない、話を切り上げたい |

### 打ち出し方で避けること
- **恋愛・モテ・色恋の話を中心にしない。** 2025年6月28日施行の改正風営法で、ホストクラブの「色恋営業」や「No.1ホスト」のように売上や指名数を強調する広告が禁止されました。規制の対象はお店で、個人の発信者ではありません。それでも、世間の目は厳しくなっています。
- **「売上〇億」「No.1」を看板にしない。** 事実でない場合や証明できない場合は、景品表示法の優良誤認にあたるおそれもあります。看板は売上ではなく、「会話の技術」にします。

## 3. 有料会員が得られるもの（練習会なしの設計）

| 内容 | 頻度 | ねらい |
|---|---|---|
| **限定記事**：場面別の雑談の型と、ホスト時代の実例 | 週1本（土曜） | 毎週読む理由をつくる |
| **相談への回答**：掲示板の「相談受付」投稿に会員がコメントで悩みを書き、記事で回答 | 月2回 | 自分の悩みに答えてもらえる体験 |
| **今月の雑談ネタ帳**：季節やニュースの話題と、その振り方 | 月1回（月初め） | 月初めに「今月も入っていてよかった」と思わせる |
| **入会直後に読む記事3本**：基本の型をまとめたもの | 最初に1回つくる | 「入会後に何をすればいいか分からない」による退会を防ぐ |

- note の掲示板に投稿できるのはオーナーだけで、会員はコメントできます。そのため、相談は「オーナーが受付の投稿を立て、会員がコメントで書く」形にします。
- DMMオンラインサロンの退会アンケートには、「オーナーの投稿が少ない」「入会後に何をすればいいか分からなかった」という選択肢があります。**投稿の曜日を固定し、入会直後の案内を用意**しておくことが、辞める人を減らす一番の対策です。

## 4. 無料の発信（集客の流れ）

```
TikTok・YouTubeショート（顔なし、月・水・金）
  ↓  プロフィールのリンク／動画内で「noteで『沈黙やぶりの雑談研究所』と検索」と案内
note の無料記事（毎週日曜）
  ↓  記事の最後にメンバーシップの案内（2027年1月から）
note メンバーシップ（月1,500円）
```

### ショート動画
- 30〜60秒、1本に1つの場面と1つの一言
- 顔なしで作る：文字と声、手元、イラストやアバター
- シリーズ名は「沈黙を破る一言」で固定する

### 誘導するときの注意
- **YouTubeショート**：2023年8月31日から、ショートの説明欄とコメント欄のリンクはクリックできなくなりました。チャンネルのプロフィールに表示されるリンクを使い、動画の中でも「noteで検索」と案内します（現在の仕様は YouTube ヘルプで要確認）。
- **TikTok**：外部へ誘導できるのは、実質的にプロフィールのリンクだけです。リンクを貼れる条件は公式情報で確認できなかったので、アプリの設定画面で確認してください。

### 必要な読者の数
- 無料の読者が有料会員になる割合は 1〜3% が目安です。
- 有料会員30人には、**熱心な無料読者が 1,000〜3,000人**ほど必要になります。
- 見るべき数字は TikTok の再生数よりも、**note のフォロワー数と、無料記事の「スキ」とコメントの数**です。

## 5. 価格とお金

| | 月額 | 手取り（1人あたり） |
|---|---|---|
| 創設メンバー（最初の10人） | 1,000円 | 約855円 |
| 通常 | 1,500円 | 約1,283円 |

- 手取りは、note の手数料（カード決済5% ＋ プラットフォーム手数料10%）を引いた試算です。振込手数料（1回270円）と税金は含みません。
- **30人（創設10人＋通常20人）での手取りは、月約3.4万円。**
- 毎月8%が辞めると考えると、30人を保つには毎月2〜3人の新しい入会が必要です。

### note の仕様で気をつけること
- 価格を変える目的で新しいプランを作っても、旧プランの会員を新プランへ移すことはできません。そのため、**「創設メンバー 1,000円」と「通常 1,500円」を別々のプランとして作ります**。創設メンバーは、ずっと1,000円のままです。
- 1,000円プランだけ新規の受付を止められるかは、確認できませんでした。**開設前に note ヘルプかサポートで確認**してください。止められない場合は、「最初の10人まで」と告知し、10人に達したら案内をやめる運用にします。
- 2026年8月3日から、新しく入った人は入会日が毎月の請求日になりました。

## 7. 法律・ルールのチェックリスト

> 一般的な情報で、法的な助言ではありません。迷ったら弁護士・税理士に確認してください。

### 会社員の副業として
- [ ] **就業規則を確認する**：副業が禁止または届出制になっていないか。顔出しなし・新しい名前での運営は身元を守るのに役立つが、規則を守ることが前提
- [ ] **確定申告**：給与所得者は、副業の所得（売上から経費を引いた額）が年20万円を超えると確定申告が必要。20万円以下でも、住民税の申告は必要
  - 2026年は売上がないので申告は不要
  - 2027年は、1月から会費が入り5月に30人に届けば、年間の売上が30万円を超える見込み。経費を引いて20万円を超えるなら、2028年2〜3月に確定申告する
- [ ] **経費の記録**：動画編集アプリ、マイク、書籍などの領収書を残す。note の売上明細もデータのまま保存する（電子帳簿保存法）

### 販売のルール
- [ ] **特定商取引法の表記**：有料メンバーシップを継続して売るなら、「販売業者」にあたる可能性が高いです。その場合、氏名・住所・電話番号の表示が原則です。ただし、「請求があれば遅滞なく開示する」と表示すれば省略できます。note では開示の請求は note 宛てに届き、note が断りなくクリエイターの個人情報を渡すことはない仕組みです。**顔出しなし・新しい名前での運営とも両立できます。**
- [ ] **誇大な表現をしない**：「誰でも必ず雑談上手に」のような断定はしない（景品表示法）
- [ ] **経歴を正確に書く**：「元No.1」などは、事実で証明できる場合だけ使う
- [ ] **恋愛・色恋の打ち出しを避ける**：改正風営法の施行以降、世間の目が厳しいため
